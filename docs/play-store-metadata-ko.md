# 집밥노트 Google Play Console 메타데이터

## 기본 정보

- 앱 이름: 집밥노트
- 기본 언어: 한국어
- 카테고리: 음식/음료
- 패키지명: `com.jipbab.note`
- 버전명: `1.0`
- 버전 코드: `1`
- 콘텐츠 등급 예상: 전체 이용가 수준

## 짧은 설명

냉장고 재료를 기록하고, 가진 재료로 만들 수 있는 집밥 레시피와 장보기 목록을 바로 확인하세요.

## 전체 설명

집밥노트는 냉장고 속 재료를 관리하고, 보유 재료를 기준으로 오늘 만들 수 있는 집밥 레시피를 찾게 돕는 모바일 앱입니다.

재료를 냉장, 냉동, 실온으로 나누어 정리하고 유통기한을 기록할 수 있습니다. 임박한 재료를 먼저 확인해 낭비를 줄이고, 보유 재료와 레시피 재료를 비교해 부족한 재료를 바로 파악할 수 있습니다.

레시피 상세 화면에서는 필요한 재료, 부족 재료, 조리 순서, 조리 체크리스트를 확인할 수 있습니다. 부족한 재료는 장보기 목록으로 옮기고, 구매 후 냉장고 재료로 다시 등록할 수 있습니다.

주요 기능

- 냉장고 재료 등록, 수정, 삭제
- 보관 위치와 유통기한 기준 재료 정리
- 유통기한 D-3, D-1, 당일 로컬 알림
- 재료명, 카테고리, 메모 검색
- 보유 재료 기반 레시피 추천
- 레시피 상세의 보유/부족 재료 비교
- 조리 체크리스트와 장보기 목록 연결
- Google/Apple/Kakao 로그인 기반 데이터 동기화
- 계정 삭제 요청 및 고객센터/개인정보 처리방침 제공

추천 대상

- 장보기 전에 집에 있는 재료를 먼저 확인하고 싶은 사용자
- 유통기한을 놓쳐 식재료를 버리는 일을 줄이고 싶은 사용자
- 오늘 뭐 먹을지 자주 고민하는 1인 가구, 가족, 요리 초보자
- 집밥, 반찬, 국/찌개, 한 그릇 메뉴를 빠르게 찾고 싶은 사용자

## 그래픽 / 스크린샷

- 휴대전화 스크린샷 5장: `docs/play-store-assets/phone`, 1080x1920 JPG
  1. 홈 화면
  2. 냉장고 재료 목록과 검색
  3. 레시피 추천 목록
  4. 레시피 상세와 부족 재료
  5. 장보기 목록
- 고해상도 앱 아이콘: `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` 및 `app/icon.png` 기준 확인
- 기능 그래픽: `docs/play-store-assets/feature-graphic.png`, 1024x500 RGB PNG
- 제출 전 `pnpm store-assets:prepare && pnpm check:store-assets`로 최신 자산을 다시 생성하고 규격을 확인합니다.

## 앱 콘텐츠 / 데이터 보안 답변 초안

앱에서 처리하는 데이터

- 이메일 주소, 닉네임, 프로필 이미지: 선택 로그인과 계정 동기화에 사용
- 앱 활동: 재료 목록, 장보기 목록, 즐겨찾기, 레시피 이용 상태
- 기기 또는 기타 ID: 로그인 전 데이터 분리와 동기화에 사용하는 로컬 기기 식별값

데이터 처리 기준

- 데이터는 HTTPS로 전송합니다.
- 계정 삭제 요청 흐름을 앱 안에서 제공합니다.
- 개인정보 처리방침 URL: `https://jipbab-note-app-youngbeens-projects.vercel.app/privacy`
- 지원 URL: `https://jipbab-note-app-youngbeens-projects.vercel.app/support`
- 광고 ID는 현재 앱 기능에 사용하지 않습니다.
- 위치 정보, 연락처, 건강 정보, 금융 정보는 수집하지 않습니다.

## 권한 설명

- 인터넷: Supabase 동기화, 레시피/상품 정보 조회, 외부 링크 이동에 사용
- 알림: 사용자가 동의한 경우 유통기한 D-3, D-1, 당일 로컬 알림에 사용

## 심사 메모

- 비로그인 상태에서도 홈, 냉장고, 레시피, 장보기, 고객센터, 개인정보 처리방침을 확인할 수 있습니다.
- 로그인은 선택 기능이며 Apple, Google, Kakao 제공자 플래그는 운영 환경변수로 제어됩니다.
- 이번 제출 버전은 카메라/바코드 스캔을 핵심 기능으로 노출하지 않습니다.
- 외부 쇼핑 링크는 사용자가 직접 탭했을 때만 브라우저로 이동합니다.
- 계정 삭제 요청은 앱의 `/account-delete` 화면에서 시작할 수 있습니다.
