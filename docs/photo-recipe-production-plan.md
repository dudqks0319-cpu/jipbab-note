# 집밥노트 사진/초보자 레시피 제작 설계

## 목표

경쟁 앱처럼 사진이 풍부해 보이되, 외부 앱/블로그/쇼핑몰 사진을 복제하지 않고 집밥노트 자체 제작 자산으로 운영한다.

## 이미지 원칙

- 재료 사진: 1:1 정사각형, 3/4 상단 시점, 무광 아이보리 배경, 부드러운 자연광, 상표/포장/텍스트/손/워터마크 없음
- 완성 요리 사진: 한국 가정식 식탁, 45도 시점, 흰색 또는 무채색 그릇, 실제 집밥 양, 과한 레스토랑 플레이팅 금지
- 앱 적용: 기존 이미지가 재료 식별에 충분하면 유지하고, 오인식 위험이 큰 fallback만 우선 교체

## 이번 교체 범위

- `chicken-raw-photo.png`: 닭고기 대표 이미지
- `tuna-raw-photo.png`: 참치/생참치 대표 이미지
- `octopus-photo.png`: 문어/낙지 대표 이미지
- `frozen-vegetable-mix-photo.png`: 냉동야채믹스 대표 이미지
- `orange-juice-photo.png`: 과일주스 대표 이미지
- `mixed-beans-photo.png`: 콩통조림/병아리콩/강낭콩 대표 이미지
- `starch-powder-photo.png`: 전분 대표 이미지
- `perilla-oil-photo.png`: 들기름 대표 이미지
- `ssamjang-photo.png`: 쌈장 대표 이미지

## 생성 프롬프트 템플릿

### 재료 사진

```txt
실사형 음식 사진. 한국 집밥 앱에 사용할 단일 재료 사진.
재료: [재료명].
신선한 [재료명]을 중심에 배치, 3/4 상단 시점, 정사각형 구도.
무광 아이보리 세라믹 배경, 부드러운 자연광, 약한 그림자.
재료의 질감과 색이 선명하게 보이도록 사실적으로 촬영한 느낌.
상표, 포장지, 글자, 라벨, 사람 손, 워터마크 없음.
과장된 광고 스타일이나 CGI 느낌 없이 자연스럽고 깨끗한 한국 마트 신선식품 사진.
```

### 완성 요리 사진

```txt
실사형 한국 집밥 완성 요리 사진.
요리: [요리명].
흰색 또는 무채색 그릇에 담긴 [요리명], 45도 시점, 정사각형 구도.
밝은 나무 식탁 위, 창가 자연광, 따뜻하고 부드러운 그림자.
국물, 윤기, 채소, 고명 등 실제 음식 질감이 선명하게 보이는 자연스러운 사진.
가정식 느낌의 정갈한 플레이팅, 과한 레스토랑 장식 없음.
상표, 텍스트, 사람, 손, 워터마크, 포장지 없음.
```

## 초보자 레시피 작성 규칙

- 재료량은 `적당량`으로 두지 않고 `큰술/작은술/ml/종이컵/모/공기`를 함께 표시
- 조리 단계마다 `팁`과 `눈으로 확인` 상태를 둔다
- 불 세기, 시간, 실패 시 조정법을 한 문장으로 적는다
- `1큰술=15ml`, `1작은술=5ml`, `1컵=약 180ml`, `한줌=약 30~50g` 기준을 사용한다

## 다음 확장 순서

1. 검수 레시피 23개: 계량/초보 팁/눈으로 확인 문구를 모두 갖춘 첫 경쟁 배치
2. 전용 완성요리 사진 15장 제작 및 curated recipe 연결
3. 앱 첫 화면에 자주 노출되는 레시피 50개를 사진 포함 curated seed로 확장
4. 대표 재료 100개 사진 커버리지 확인
5. 레시피별 단계 이미지 또는 단계 설명용 보조 사진 추가
6. 사진 출처 문서 누락 시 release check에서 실패 처리: 2026-05-06 1차 적용 완료

## 경쟁 배치 1 레시피 범위

- 기존: 김치볶음밥, 된장찌개, 계란말이, 두부조림, 돼지고기 김치찌개, 감자조림, 간장마늘 닭조림, 참치김치볶음밥
- 추가: 간장계란밥, 계란찜, 콩나물국, 오이무침, 제육볶음, 소고기 미역국, 카레라이스, 떡만두국, 비빔국수, 참치마요덮밥, 양배추계란볶음, 어묵볶음, 시금치나물, 김치전, 토마토계란볶음
- 품질 기준: 모든 검수 레시피는 구조화된 재료량, 계량 기준, 초보자 요약, 단계별 팁, 단계별 시각 확인 문구를 가진다.
