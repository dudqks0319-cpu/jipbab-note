# 집밥노트 로컬 LLM 다운로드/실행 전략

## 결론

사용자가 앱 안에서 경량 LLM을 다운로드하고 오프라인으로 쓰는 구조는 가능합니다.

다만 현재 집밥노트의 `Capacitor WebView + 원격 웹앱` 구조에 바로 붙이는 방식은 권장하지 않습니다. 모델 다운로드/실행은 네이티브 런타임이 필요합니다.

권장 방향:

1. 단기 출시 버전에는 로컬 LLM을 넣지 않는다.
2. 출시 후 별도 마이너 버전에서 `온디바이스 AI` 기능으로 추가한다.
3. iOS/Android 네이티브 런타임을 붙이고, WebView UI는 그 런타임을 호출하는 구조로 간다.

## 모델명 정리

사용자가 말한 `gamma4 2b`는 공식 명칭으로는 확인되지 않았습니다.

가능성이 높은 후보:

- Gemma 2 2B
- Gemma 2B
- Gemma 3n E2B
- Gemma 4 E2B 계열

앱에서 사용자 다운로드형으로 제공할 때는 정확한 모델명/라이선스/배포 파일 형식을 먼저 확정해야 합니다.

## 현재 Mac 개발 환경 확인

현재 개발 Mac:

- Apple M3 Max
- 36GB RAM
- `ollama` 설치됨

따라서 개발자 로컬 테스트는 가능합니다.

다만 `ollama`는 사용자의 iPhone 안에서 돌아가는 런타임이 아닙니다. iOS 앱에 넣으려면 iOS용 LLM 런타임이 별도로 필요합니다.

## 앱 안에서 다운로드해서 쓰는 구조

### UI 흐름

1. 설정 또는 AI 추천 화면에 `오프라인 AI 모델 설치` 섹션 노출
2. 사용자가 모델 크기와 저장공간 안내를 확인
3. 모델 다운로드 시작
4. 다운로드 완료 후 로컬 추론 활성화
5. 사용자가 삭제할 수 있는 `모델 제거` 버튼 제공

### 기능 예시

집밥노트에서 로컬 LLM은 다음 정도에 맞습니다.

- 냉장고 재료 기반 자연어 추천
- "양파, 계란, 두부로 뭐 해먹지?" 답변
- 초보자용 조리 설명 풀어쓰기
- 유통기한 임박 재료 활용 아이디어

민감한 영역:

- 의학/영양 처방처럼 보이는 답변
- 알레르기/임산부/질병 관련 확정적 조언

이런 문장은 안전 문구와 제한이 필요합니다.

## 기술 선택지

### 1. Google AI Edge / MediaPipe / LiteRT 계열

장점:

- Gemma 모바일 배포 경로와 잘 맞음
- iOS/Android 온디바이스 실행 사례가 있음
- `.task`, `.bin`, LiteRT 계열 모델 배포가 가능

단점:

- 현재 앱 구조에서는 네이티브 브릿지 작업이 필요
- 모델 변환/호환성 검증 필요
- 기기별 성능 편차 큼

### 2. MLC LLM / llama.cpp 계열

장점:

- 다양한 소형 모델 지원 가능
- 커뮤니티 자료가 많음

단점:

- iOS 앱스토어 배포용 통합과 유지보수 난이도가 높음
- 모델 파일, Metal/GPU, 메모리 이슈를 직접 다뤄야 함

### 3. 서버/클라우드 LLM

장점:

- 구현 빠름
- 모델 품질 높음

단점:

- 오프라인 불가
- 비용/개인정보/응답 지연 리스크

## App Store 리스크

모델 파일 다운로드 자체는 가능하지만, 다음을 지켜야 합니다.

- 앱 심사 시 핵심 기능이 무엇인지 명확해야 함
- 다운로드한 리소스가 앱 기능을 심사 당시와 크게 바꾸는 "새 코드"처럼 보이면 안 됨
- 모델 삭제/저장공간 안내 필요
- 개인정보가 기기 밖으로 나가지 않는다면 그 점을 명확히 안내

## 권장 구현 순서

### Phase 1: 연구/프로토타입

- 실제 iPhone 16 Pro에서 Gemma 2B/E2B 계열 실행 테스트
- 응답 속도, 발열, 메모리, 배터리 기록
- 추천 프롬프트 품질 테스트

### Phase 2: 네이티브 브릿지

- Capacitor plugin 또는 별도 native module 작성
- JS에서 `generateRecipeIdeas(prompt)` 형태로 호출
- 모델 설치 상태 API 추가

### Phase 3: 사용자 다운로드 UI

- 모델 크기/저장공간 안내
- 다운로드 진행률
- 모델 삭제
- 오프라인 모드 표시

### Phase 4: 출시

- App Store Review 메모에 온디바이스 모델 설명
- 개인정보 처리방침에 로컬 처리 명시
- 안전 문구와 한계 고지 추가

## 현재 결론

집밥노트에 로컬 LLM을 넣는 것은 제품 방향상 좋습니다.

하지만 앱스토어 첫 출시 범위에는 넣지 않는 것이 맞습니다.

첫 출시 후 안정화된 다음, `온디바이스 AI 추천` 기능으로 별도 릴리즈하는 것을 권장합니다.
