# 집밥노트 출시 우선순위 구현 체크리스트

## 변경 전 점검

- [x] 출시 하네스: `pnpm test` 통과, `pnpm release:check` 하드 블로커 0개
- [x] 계정 삭제: 앱 내 요청, 운영자 처리 API, 실제 auth/user 데이터 삭제 경로 존재
- [x] 제휴 링크: DB 관리, `rel="sponsored"`, 파트너 링크 하네스 존재
- [x] 홈: 냉장고 요약과 추천 레시피 3개 존재
- [x] 냉장고: 기본 재료 5개 담기, 추천 칩, 중복 병합, 빠른 유통기한 선택 존재
- [x] 레시피: 초보 검수 큐레이션 20개 이상, 상세 계량/팁/조리 모드 존재
- [x] 장보기: 부족 재료 추가, 구매 후 냉장고 추가 존재
- [ ] 홈 첫 답변성: 오늘의 1순위 추천이 최상단에 없음
- [ ] 재료 일괄 입력: 여러 줄 붙여넣기 없음
- [ ] 소진 상태: 삭제 대신 소진 기록 UX 부족
- [ ] 알림: 알림 스케줄 생성 로직은 있으나 설정 화면과 연결 부족
- [ ] 레시피 출처: DB 원천/라이선스 추적 테이블 없음
- [ ] 추천 이유: `% 일치` 중심으로 자연어 설명 부족
- [ ] 제휴 고지: 구매 버튼 근처 반복 고지 부족
